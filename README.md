# Player-Imitating AI in Combat Game

This project explores creating an NPC that imitates a player’s playstyle in a third-person combat game using a logic-based behavior graph. The AI observes player actions such as movement and attacks, and adapts its behavior accordingly, providing a more responsive and engaging experience compared to traditional, predictable NPCs.

## Running the Project

- **Play the final build:** Download and run `GradWorkBuild.zip`.  
- **Open in Unity:** Use the `Assets`, `Packages`, and `ProjectSettings` folders to open the project in Unity and inspect or modify the AI logic.

## Notes

This project was developed as a graduation work at Howest University of Applied Sciences, Digital Arts & Entertainment (DAE), exploring player-driven AI without machine learning.
